# Базар

Онлайн-продажа фруктов и овощей с доставкой (Армения / Грузия / Россия).

## Состав

- [`weight-rules/`](weight-rules/README_RU.md) — правила весовых товаров: котировка,
  допуск подбора, проверка фактической сборки, уведомления на hy/ru/ka.

## Проверка

```sh
node --test weight-rules/weight-policy.test.mjs
```

Node.js 18+, без зависимостей.
