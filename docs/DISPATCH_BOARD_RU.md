# Доска доставок и назначение курьера

`POST /api/manage/dispatch/board` (владелец): `{"day":"2026-12-10","area":"Бавра","from":600,"to":780}`.
Показывает доставки дня с временем, населённым пунктом, адресом и текущим курьером; можно отфильтровать по населённому пункту и интервалу (минуты от полуночи).

`POST /api/manage/dispatch/assign` (владелец): `{"order_ids":["BZ-…","BZ-…"],"driver_id":"<id курьера>"}`.
Назначает одного курьера на несколько заказов. Каждый заказ проверяется отдельно через существующее назначение (`action: assign`): курьер должен быть в этом городе, заказ — доставкой. Ответ — результат по каждому заказу; сбой одного не отменяет остальные. Максимум 100 заказов за раз.

Это отдельный модуль `src/dispatch-board.mjs`. Файл `src/dispatch.mjs` — логика диспетчера в Telegram, его не меняли.

Время доставки по программе должно быть из сетки слотов (каждые 30 минут от 09:00): иначе планировщик не найдёт точный слот. Если точного слота нет, доставка уходит на ближайший свободный, а не на самый ранний.
