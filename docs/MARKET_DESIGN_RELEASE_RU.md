# Оформление рынка и рекламные места

17 октября 2026. Владелец подтвердил текущие цены и ассортимент для публикации, разрешил убрать обозначения демо. `config.demo=false`; начальные цены/остатки не перезаписываются. Новые списки импортировать через управление каталогом, не затрагивая снимки заказов. Миграция 0005 меняет только исходные учебные названия двух поставщиков, сохраняя пользовательские названия, ID и историю. Адрес Worker `bazar-demo` сохранён ради действующего API и webhook.

По уточнению владельца сцена рынка находится ТОЛЬКО на открывающейся шторке. На постоянном первом экране нет мужчины или сцены с продавцом: только вступительный текст и переход к покупкам, затем акции. Изображение `public/media/bazar-opening-market.jpg` создано ImageGen 17.10.2026: иллюстрация базара с навесами, прилавками и небольшими фигурами людей, без главного персонажа. Предыдущий портрет удалён из опубликованных файлов.

Вступление объединено с исходным экраном загрузки: один `#market-entry` находится в HTML вне `#app`. Отдельная загрузочная надпись и динамическая шторка удалены. На общей сцене рынка размещены три вывески: «БАЗАР», «ԲԱԶԱՐ», «ბაზარი». Названия — доступный HTML, не сгенерированный текст на картинке.

После готовности каталога и изображения экран мягко уходит за 0,7 с; минимальная видимость 1,1 с, при зависшей загрузке выход начинается максимум через 3 с. Кнопка перехода к покупкам позволяет выйти сразу. Если модуль JavaScript не загрузится, CSS самостоятельно скрывает вступление через 5 с. При reduced-motion вступление отключено. Нет sessionStorage-флага, из-за которого при повторном открытии пропадала шторка; повторная отрисовка каталога не создаёт новый экран. Обработка готовности изображения основана на `HTMLImageElement.decode()` с обработкой ошибки: https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/decode . Reduced motion: https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion .

Сразу под первым экраном — яркие карточки «Акции» и «Вечерний базар», затем настоящие предложения из D1. Скидки и активность не выдумываются. Если предложений нет, показано сообщение об отсутствии.

## Реклама своих проектов

Кабинет → «Реклама проектов». Два места: после первого экрана и перед подвалом. Для каждого — название/описание на русском, армянском и грузинском, HTTPS-ссылка, картинка HTTPS или `./media/name.jpg`, переключатель показа. Пустые/выключенные места скрыты. Ссылка помечена как реклама, открывается отдельно с `noopener noreferrer sponsored`. Баннер не загружает сторонние рекламные скрипты.

API: GET/POST `/api/manage/advertising` — только владелец; данные в `app_config`, атомарная проверка версии и запись в `operations_audit`. Публичные включённые баннеры возвращаются в `/api/bootstrap`; телефоны и персональные данные в них не передаются. Повтор со старой версией отклоняется. `src/advertising.mjs` и `public/advertising.js` подготовлены для переноса в другие проекты. Эталонные репозитории не изменялись; взаимный показ на остальных сайтах потребует внедрения того же модуля в каждом из них.

Новые автоматические проверки: скрытые места по умолчанию, права владельца, запрещённые URL, заполнение трёх языков, конфликт версий и аудит. Визуальная браузерная проверка не выполнена: доступ к локальному браузерному предпросмотру ранее отклонён автоматической проверкой разрешений; обход не применялся.

Дополнительные регрессионные проверки: ровно одно вступление в начальном HTML, три названия, отсутствие динамической второй шторки/sessionStorage; готовность фото и каталога, зависшие запросы, ручной выход, reduced-motion. Всего 59/59 тестов, сборка Worker и разбор CSS успешны. Визуальная проверка в браузере по-прежнему не выполнялась.
