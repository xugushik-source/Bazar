# План доставок на период — «Забота о близких»

`POST /api/manage/subscriptions/plan` (только владелец), тело: `{"from":"2026-12-01","to":"2026-12-10"}`.

Для каждого дня показывает: сколько доставок, по скольким программам, статусы и суммарный список товаров
(граммы и штуки по каждому товару). Список нужен, чтобы знать, что загрузить в этот день.

- Ничего не резервирует и не создаёт заказов. Остатки не меняются.
- Учитываются только активные программы; отменённые и пропущенные доставки не входят.
- Период — не больше 120 дней, даты в формате YYYY-MM-DD.

Важно: создание заказа (`createOrder`) по-прежнему уменьшает остаток товара в каталоге. Если товары
закупаются «с колёс» и не лимитированы, нужно снять для них лимит остатка или отдельно решить,
создавать ли заказы программы заранее. Это отдельное решение владельца.
